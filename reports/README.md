# reports/

Deliverables produced in this workspace by either Claude Desktop or Claude Code: tenant letters,
research write-ups, migration plan drafts, shopping lists, summaries for Mat.

Plain text (.txt or .md), dated filename, e.g. `2026-10-21-supplier-research-10g-optics.md`.
Mat reads on an old phone: short lines, no HTML, no artifacts. Facts that should outlive the
report go in `notes/` (see `notes/MEMORY.md`); the report cites them.

Older reports made on the jump box live in `jumpbox-setup/` (DISCOVERY-REPORT, SWITCH-MAP,
SHOPPING-LIST, BOOTSTRAP-SHEET-CROSSREF). They stay there.
